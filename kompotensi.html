KOMPOTENSI

HTML

HTML adalah bahasa markah standar yang di gunakan untuk membuat dan menyusun struktur dasar halaman seta aplikasi website

CSS

CCS adalah bahasa stylesheet yang di gunakan untuk mengatur tampilan,gaya,dan tata letak,dokumen atau halaman website yang di tulis dalam bahasa markup seperti HTML

JAVASCRIPT

JavaScript adalah pemograman yang di gunakan untuk membuat halaman website menjadi dinamis,dan hidup

PHP

PHP adalah pemograman scripting yang berjalan di sisi server (backend/server-side) khusus untuk pengembangan website dinamis dan aplikasi website
